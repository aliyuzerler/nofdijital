# Testing & QA Skill
- Read current phase test checklist; never skip a failing gate.
- Use Vitest for unit/integration and Playwright for E2E/visual.
- Compare same viewport and state against the provided HTML.
- Test Turkish text, long content, missing optional settings and empty states.
- Test anonymous, owner and editor roles.
- Verify draft/public boundaries, publish cache invalidation, redirects and upload constraints.
- Record commands, exit codes, traces/screenshots and known blockers.
- Never claim a test ran if it did not.
